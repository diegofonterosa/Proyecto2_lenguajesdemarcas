# Proyecto 2 - Lenguajes de Marcas

Proyecto de la asignatura **Lenguajes de Marcas y Sistemas de Gestión de Información**.  
Consiste en la creación y validación de documentos XML mediante DTD y XSD.

## Autor

**Diego Fonterosa**

## Descripción

Este repositorio contiene tres ejercicios en los que se trabaja con documentos XML bien formados y validados, utilizando dos métodos de validación: DTD (Document Type Definition) y XSD (XML Schema Definition).

## Estructura del repositorio

```
Proyecto2_lenguajesdemarcas/
├── Ejercicio1/
│   ├── catalogo.xml    # Documento XML con datos de un catálogo
│   ├── catalogo.dtd    # Validación mediante DTD
│   └── catalogo.xsd    # Validación mediante XSD
├── Ejercicio2/
│   ├── plataforma.xml  # Documento XML con datos de una plataforma
│   ├── plataforma.dtd  # Validación mediante DTD
│   └── plataforma.xsd  # Validación mediante XSD
└── Ejercicio3/
    ├── library.xml     # Documento XML con datos de una biblioteca
        ├── library.dtd     # Validación mediante DTD
            └── library.xsd     # Validación mediante XSD
            ```

            ## Tecnologías utilizadas

            - **XML** - Lenguaje de marcas para estructurar los datos
            - **DTD** - Document Type Definition para la validación de documentos XML
            - **XSD** - XML Schema Definition para la validación de documentos XML

            ## Ejercicios

            ### Ejercicio 1 - Catálogo
            Documento XML que representa un catálogo de productos, validado tanto con DTD como con XSD.

            ### Ejercicio 2 - Plataforma
            Documento XML que modela una plataforma, con su correspondiente validación DTD y XSD.

            ### Ejercicio 3 - Biblioteca (Library)
            Documento XML que representa una biblioteca con sus recursos, validado mediante DTD y XSD.
